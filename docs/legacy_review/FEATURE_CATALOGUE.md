# FEATURE CATALOGUE - GYANAM AI, NLU Jodhpur Edition (Powered by Kelyvo), http://localhost:3000/

Sources: ANALYSIS.md (A, source + HTTP API, 43 operations), OPERATOR_LOG.md + part02-08 (O, browser use of all 6 roles). Evidence column: A / O / both.
Status: real = backed by actual backend logic/data; demo = works but canned/templated/simulated output; hard-coded = static client text/data; placeholder = label or number not driven by data; dead = code with no UI; unlinked = served but not reachable from UI.
Platform: FastAPI/uvicorn single page (406 KB index.html, Tailwind CDN, one inline script, ~96 functions), 7 workstation tabs, 4 modals, 6 passwordless personas, SQLite FTS5 BM25 corpus of 118,096 judgments (SC 4,611 + 25 HCs 113,485; status FOLLOWED 118,094 / OVERRULED 2). English only, light theme only, no ARIA.
"Roles" column abbreviations: J=Judicial/Authorized User, R=Researcher/Law Clerk, F=Faculty, S=Student, Ad=Administrator, Au=Auditor, all=every role.
