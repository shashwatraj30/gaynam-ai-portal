## Overview
- FastAPI/uvicorn app; title "Gyanam AI - NLU Jodhpur Edition (Powered by Kelyvo)". Single HTML page `/` = 406,276 bytes, 6,708 lines: Tailwind via CDN (cdn.tailwindcss.com), Google Fonts (Outfit, Plus Jakarta Sans, Source Serif 4, Space Grotesk), inline SVG icon sprite (~40 icons), one inline `<script>` (lines 2408-6706, ~70 functions) and inline `<style>` (lines 53-188, incl. `@media print` at ~178).
- Static assets: /static/nluj_seal.png (74 KB), /static/gyanam_emblem_transparent.png (535 KB), /static/kelyvo_logo.png (295 KB), /static/nlu_campus_real.jpg (417 KB), /static/SYSTEM_ARCHITECTURE_AND_TENDER_DOSSIER_GYANAM_AI.pdf (15,152 B). /static/ itself = 404.
- Extra served pages: /presentation and /slides (same 26,969-byte HTML, 7-slide "GYANAM AI - End-to-End Judicial RAG Presentation" with prev/next, "1 / 7" counter), /pdf, /architecture.pdf, /dossier.pdf, /dossier (all = same 15 KB PDF dossier), /docs (Swagger UI, loads from jsdelivr), /redoc, /openapi.json. 404 on /health, /legacy, /app.
- 7 workstation tabs (switchTab ids): tab-dashboard, tab-research (default), tab-citation, tab-intake, tab-studio, tab-graph, tab-audit. Plus modals: auth-gateway-modal (role switcher), case-modal (judgment dossier), docs-modal (institutional docs), doc-photo-modal (scanned doc zoom).
- Left sidebar (#app-sidebar, w-72/80): logos, campus photo card with Sanskrit motto "ज्ञानम् परमम् ध्येयम् • CJLT", SESSION ROLE card + "Switch ESC" button, WORKSTATIONS nav (7 tabs with role-dependent badges), INSTITUTIONAL > "Tender Dossier" (opens docs modal), "Live Judicial Dispatch" live case feed + Sync button, footer (counter "1,17,988 Active", Sync, "DPDP 2023 Air-Gapped Local AI", "Powered by Kelyvo", "v2.5.0"). Retractable to a mini icon rail.
- Top bar: "Wide Screen" sidebar toggle (id btn-sidebar-retract), breadcrumb "NLU Jodhpur / <tab title h1#top-bar-workstation-title>", Sanskrit chip (xl screens), "Sovereign Local Node (1.18L)" pill, persona pill (opens role modal), Kelyvo logo "Engine By KELYVO".
- Auth model: NO password. Role is picked from a modal; client POSTs /api/auth/sso/nluj {target_role, institutional_domain:'nlujodhpur.ac.in'} and receives a JWT (HS256; payload user_id,email,full_name,designation,institution,role,scope_role,badge_id,dpdp_consent,exp,iat,iss=gyanam-ai.nlujodhpur.ac.in,sub,vendor="Powered by Kelyvo"; ~24h lifetime). currentAuthToken is stored in a JS variable only; sessionStorage key `gyanam_session_active`='true'. Most data endpoints are NOT token-checked (all GETs I called worked with no Authorization header; /api/auth/me with no header returns the default judge, with bogus bearer returns 401). Role gating is client-side (applyRoleUI) (see Roles).
- Hard-coded default text in HTML differs from live data (e.g. dashboard shows "1,18,000", "4,515 SC", "2,480+", "18+", "98.4%", "7 Oct 2026, 01:20 AM" until loadDashboardMetrics overwrites; search badge "1,18,003 Judgments Indexed"; sidebar "1,17,988 Active").
- Live status (GET /api/status, 2026-10-26): ONLINE; 118,096 judgments indexed; engine "SQLite FTS5 Hardware-Accelerated BM25"; 26 court entries in court_distribution (SC + 25 HCs); status_distribution FOLLOWED 118,094 / OVERRULED 2; sync: ONLINE_ACTIVE, 9 monitored courts, SCitation-v3.4-IN, TLS 1.3/AES-256; compliance flags dpdp_act_compliant, air_gap_ready, zero_external_training, tamper_evident_ledger all true. Storage path text: "/opt/gyanam_ai/data/gyanam_legal.db".
