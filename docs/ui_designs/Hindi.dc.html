Type for Devanagari
Noto Sans Devanagari for the interface and Noto Serif Devanagari for headings and reading text, both self-hosted. Line heights are taller than Latin: body 15/26, reading 17/32, H1 38/52, H2 21/32, so matras above and below the line are never clipped.
What is translated
Menus, buttons, labels, status words and help text. Judgments, case titles and citations stay in their original language. There are no Hindi summaries of judgments.
Checks
Chips and buttons grow in width, never truncate. Hindi strings need a native-speaker review before release.
