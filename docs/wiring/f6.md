# F6 wiring requests

## frontend/app/js/api.js (not owned by F6)
`api.auditCsv` must accept filter params (audit.js already calls `api.auditCsv(params)`; params may include
`action,user,role,q,since,until,bom`):

before:
```js
auditCsv: () => request('/api/export/audit_csv', { blob: true, timeout: 60000 }),
```
after:
```js
auditCsv: (params) => request(`/api/export/audit_csv${qs(params)}`, { blob: true, timeout: 60000 }),
```
