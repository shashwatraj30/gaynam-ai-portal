# Wiring request from F2 (document workspace)

File: frontend/app/index.html, CSP meta tag.
Before: img-src 'self' data:; ... frame-src 'self' https://*.amazonaws.com ...
After:  img-src 'self' data: blob:; ... frame-src 'self' blob: https://*.amazonaws.com ...
Why: the original PDF of an uploaded document is fetched with the bearer token and shown from a blob: URL in the PDF viewer iframe. Images already work (shown as data: URLs). Without blob: in frame-src the PDF preview is blank and only the Open original link works.
